# Screenshots

Screenshots in this wiki come from real KLIPSLICE builds only. No mock-ups, no
edited or composited images, and no screenshots of OrcaSlicer presented as
KLIPSLICE. There are no screenshots yet because there are no release builds; a
page gets one when a build exists that shows the feature.

This file is excluded from the site build (`exclude_docs` in `mkdocs.yml`).

## Capture specification

| Property | Value |
|---|---|
| Window size | 1600 × 1000 px (logical pixels, window content without OS shadow) |
| Scale | Captured at 2× on HiDPI displays, stored as-is |
| Theme | KLIPSLICE dark theme |
| Language | English UI for `*.png`; German UI for the `*.de.png` counterpart |
| Model | `Voron_Design_Cube_v7` from the bundled handy models (`resources/handy_models/`), unless the page needs a different model, on the Generic Klipper Printer 0.4 nozzle profile unless the page is about a specific printer |
| Content | No personal data: no host names, IP addresses, API keys, user names or file paths from a private machine |
| Format | PNG, losslessly optimised; no JPEG |
| Build | Record the KLIPSLICE commit the screenshot was taken from in the commit that adds it |

## File naming

`<page>-<subject>.png` and `<page>-<subject>.de.png`, for example
`klipper-setup-exclude-objects.png`. Reference the English file from `<page>.md` and
the German file from `<page>.de.md`.
